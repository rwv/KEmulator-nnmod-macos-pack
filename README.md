# KEmulator macOS App Package

This repository contains scripts to package [KEmulator](https://github.com/shinovon/KEmulator) v2.20 into a self-contained macOS .app bundle with bundled JRE for easy installation and use on macOS.

## What is KEmulator?

KEmulator is an emulator for J2ME (Java 2 Micro Edition) applications and games, supporting CLDC, MIDP, and various vendor-specific APIs. It allows you to run mobile Java applications and games from the early 2000s era on modern computers.

## Quick Start

### Option 1: Download Pre-built App (Recommended)

1. Download the latest release from the [Releases](../../releases) page
2. Extract the .zip file 
3. Move `KEmulator.app` to your Applications folder
4. Double-click to launch, or drag .jar files onto the app icon

### Option 2: Build from Source

Choose between two packaging methods:

#### Method A: jpackage with Bundled JRE (Recommended)
Creates a self-contained app that doesn't require Java to be installed on the user's system.

```bash
git clone https://github.com/rwv/KEmulator-nnmod-macos-pack.git
cd KEmulator-nnmod-macos-pack
./package-jpackage.sh
```

#### Method B: Manual Packaging (Legacy)
Creates a smaller app bundle but requires Java to be installed on the user's system.

```bash
git clone https://github.com/rwv/KEmulator-nnmod-macos-pack.git
cd KEmulator-nnmod-macos-pack
./package.sh
```

Both methods will create a ready-to-use `KEmulator.app`.

## Installation

### System-wide Installation
```bash
sudo cp -R KEmulator.app /Applications/
```

### User Installation
```bash
cp -R KEmulator.app ~/Applications/
```

## Usage

### Launch KEmulator
- **GUI**: Double-click `KEmulator.app` in Finder
- **Command line**: `open KEmulator.app`

### Run J2ME Applications
- **Drag & Drop**: Drag .jar or .jad files onto the KEmulator.app icon
- **Right-click**: Right-click .jar files → "Open With" → "KEmulator"
- **Command line**: `open KEmulator.app --args /path/to/game.jar`

### File Associations
The app bundle is configured to handle:
- `.jar` files (Java Archive)
- `.jad` files (Java Application Descriptor)

## Requirements

### jpackage Build (Recommended)
- **macOS**: 10.9 or later
- **Build Requirements**: Java 14+ (for building only)
- **Runtime**: Self-contained, no Java installation required

### Manual Build (Legacy)
- **macOS**: 10.9 or later
- **Java**: Java 8 (recommended) or Java 11+
  - The app will automatically detect Java installations using `/usr/libexec/java_home`
  - Install Java from [Adoptium](https://adoptium.net/) if needed

## Features

- **Self-contained Distribution**: jpackage bundles a JRE, eliminating Java installation requirements
- **Native macOS Integration**: Proper .app bundle with file associations
- **Automatic Java Detection**: (Manual build) Finds the best Java version automatically
- **Error Handling**: User-friendly error dialogs using AppleScript
- **Drag & Drop Support**: Launch games by dropping files on the app icon
- **Universal Binary Support**: Works on both Intel and Apple Silicon Macs
- **GitHub Actions**: Automated builds for macOS, Linux, and Windows

## Automated Builds

This repository includes GitHub Actions workflows that automatically build KEmulator packages for multiple platforms:

- **macOS**: Self-contained .app bundle with bundled JRE
- **Linux**: AppImage-style application with bundled JRE
- **Windows**: Executable application with bundled JRE

The builds are triggered on:
- Push to main/develop branches
- Pull requests
- Git tags (creates releases)
- Manual workflow dispatch

| Feature | jpackage Build | Manual Build |
|---------|----------------|--------------|

## Troubleshooting

### "KEmulator.jar not found" Error
This means the .app bundle wasn't packaged correctly. Run the packaging script again.

### Java Not Found (Manual Build Only)
Install Java 8 or 11+ from [Adoptium](https://adoptium.net/). The app will automatically detect it.

### Game Won't Load
- Ensure the .jar file is a valid J2ME application
- Some games may require specific device profiles or settings within KEmulator

## Project Structure

### jpackage Build
```
KEmulator.app/
├── Contents/
│   ├── Info.plist              # App metadata and file associations
│   ├── MacOS/
│   │   └── KEmulator           # Native launcher (generated by jpackage)
│   ├── app/                    # Application files
│   │   ├── KEmulator.jar       # Main emulator
│   │   ├── *.dylib            # macOS native libraries
│   │   ├── lang/              # Language files
│   │   └── uei/               # J2ME API implementations
│   └── runtime/               # Bundled JRE
│       └── Contents/Home/     # Java runtime
```

### Manual Build
```
KEmulator.app/
├── Contents/
│   ├── Info.plist              # App metadata and file associations
│   ├── MacOS/
│   │   └── KEmulator           # Launch script
│   └── Resources/              # KEmulator files
│       ├── KEmulator.jar       # Main emulator
│       ├── *.dylib            # macOS native libraries
│       ├── lang/              # Language files
│       └── uei/               # J2ME API implementations
```
